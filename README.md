# Global-AI-Job-Market-Salary-Trends-2025

## Project Overview

This project explores salary dynamics in the global AI job market using exploratory data analysis (EDA) and machine learning techniques.
The goal is to understand which factors truly influence salaries and how different variables interact in real-world compensation structures.

## Objective
- Identify the main drivers of salary variation in AI-related roles
- Analyze the impact of experience, education, geography, company size, and other factors
- Build predictive models to estimate salary and evaluate feature importance
- Understand structural patterns in salary distributions across groups

## Key Findings
- Salary distribution is right-skewed, with a small number of high earners
- Experience level is the strongest driver of salary differences
- Company location has a moderate effect
- Company size shows a secondary influence
- Employment type, education, job title, industry, and work mode have weak or inconsistent effects
